# Security Policy

## Supported Versions

Only the latest 2.x release gets security fixes.

| Version | Security fixes |
| ------- | -------------- |
| 2.x     | Yes            |
| 1.x     | No             |

## Report a Vulnerability

Do not report a vulnerability in a public issue, a pull request, or a discussion.

Report it privately with the [GitHub vulnerability report form](https://github.com/mcamara/laravel-localization/security/advisories/new).

Include this information in the report:

- The version of this package, Laravel, and PHP.
- The class, method, or middleware that has the problem.
- The request or the steps that show the problem.
- What an attacker can do with it.

The maintainers discuss the report with you in the private advisory before they publish a fix.
